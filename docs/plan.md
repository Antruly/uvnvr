# 软录像机（NVR）需求规格说明书

版本：V0.1 草案  
文档性质：需求整理稿  
说明：本文档将原始需求整理为可开发、可评审、可验收的需求文档。文中默认值均为建议初始值，实际以配置项为准。

---

## 1. 项目概述

本项目为一套软件实现的网络录像机（NVR）系统，支持接入市面常见网络摄像头，兼容 ONVIF 协议、标准 RTSP 流、海康、大华等品牌摄像头协议。系统提供摄像头通道管理、实时预览、录像计划、切片录像存储、录像索引、回放与预读取、多客户端流分发、对外 RTSP/API、用户权限、审计日志、系统设置、智能预警、GPU 加速识别与性能自适应等能力。

系统以 Web 管理端为主要操作入口，默认首页为摄像头实时预览页面。整体采用全异步 IO 架构，Linux 环境下支持 `io_uring`，Web 框架与文件框架使用 `libuvcpp`。开发过程采用 AI 驱动方式，使用 `uvp-agents` 搭建服务框架、前端模板和后台模板，命令为：`npm install uvp-agents@0.4.0`。

---

## 2. 建设目标

1. 支持多品牌、多协议摄像头统一接入与通道化管理。
2. 支持稳定、连续、低延迟的实时预览与录像回放。
3. 支持高性能录像切片写入、SQLite 索引、缓存预读与无缝播放。
4. 支持多客户端并发预览与流分发，单客户端异常不影响整体性能。
5. 支持完整的用户、角色、API 权限、Web 功能权限与安全锁定机制。
6. 支持录像计划、存储策略、磁盘管理、日志审计、系统时间同步与运维模式。
7. 支持对外 API 与 RTSP 输出，满足抓拍、预览、下载、预警等集成需求。
8. 支持 GPU 自动识别与 FFmpeg 命令自适应，支持显式关闭 GPU 使用 CPU。
9. 支持后续实验性扩展人脸识别、车牌识别。
10. 形成可复用的 UVP 前后台模板模块，并反哺 UVP、libuvcpp 开源生态。

## 3. 总体架构与技术约束

### 3.1 技术栈与基础框架

- Web 框架：`libuvcpp`。
- 文件框架：`libuvcpp`。
- 全流程异步 IO 控制。
- Linux 系统支持 `io_uring` 开启能力。
- 本地数据库：SQLite，用于存储录像文件索引、通道配置、用户权限、审计日志等。
- 流媒体处理：FFmpeg，支持按运行环境自动调整处理命令。
- 协议接入：ONVIF、RTSP、海康/大华等品牌协议或可配置协议。
- 开发方式：AI 驱动开发，使用 `uvp-agents@0.4.0` 快速搭建 `libuvcpp` 服务框架、前端模板、后台模板和标准 Web 框架。
- Web UI：左侧菜单可收起/展开，右侧为主工作区；支持多菜单缓存 Tab 页，切换不丢失原页面数据。

### 3.2 架构原则

- 通道、流媒体、录像存储、索引、缓存、预读、权限、日志等模块解耦。
- 存储模块独立封装，应用层只按“索引 + 文件流位置”读取录像文件流，不关心底层来自缓存还是硬盘。
- 录像写入采用异步 IO + 内存缓存 + 批量顺序写入。
- 内存缓存可采用环形缓存设计，环形缓存留空一格用于识别头尾。
- 实时性优先：带宽或处理性能不足时，允许丢帧、处理最新帧、降低帧率或码率以保持平衡。
- 视频文件原则上不可删除，仅通过启动参数进入内部运维模式后开放删除、日志删除、修改序列号、修改版本号等能力。

## 4. 功能需求

### 4.1 摄像头接入与通道管理

1. 支持接入 ONVIF 协议摄像头。
2. 支持直接接入 RTSP 流。
3. 支持海康、大华等品牌摄像头协议或可配置协议接入。
4. 支持自动扫描局域网摄像头，并支持一键添加。
5. 支持通道新增、编辑、删除、启用、禁用。
6. 支持通道名称、协议类型、IP、端口、账号、密码、主码流地址、子码流地址等配置。
7. 支持主码流和子码流；子码流可关闭。
8. 支持每通道媒体参数配置，包括码率、编码格式 H.264/H.265、分辨率、帧率等。
9. 支持摄像头水印设置：可拖动水印画面位置，可设置水印文字。
10. 支持通道配置一键同步到其他通道。
11. 支持通道管理显示每个摄像头的在线时间、离线时间等信息。
12. 支持摄像头掉线检测与自动重连机制。
13. 支持掉线通道在预览页显示通道名称等信息，并提示“设备已掉线”。
14. 掉线通道双击可打开该摄像头管理地址网页；在线普通摄像头双击进入全屏视频画面。

### 4.2 实时预览与多画面布局

1. 系统主页默认进入摄像头预览页面。
2. 支持 1、4、8、16、32 画面网格。
3. 支持自定义网格，支持拖动每个网格大小。
4. 支持保存布局设置。
5. 支持配置多个布局，通过布局标签切换。
6. 进入默认布局时，自动加载当前模板全部预览实时画面。
7. 支持单画面全屏、双击全屏。
8. 支持多客户端同时预览同一通道，流分发不卡顿、不丢失性能。
9. 实时预览优先保证实时性；性能不足时按策略丢帧、取最新帧、降低帧率或码率。
10. 预览和回放应自动无缝加载录像文件，建立预读取机制，保证画面连续性。

### 4.3 录像计划与配置同步

1. 支持录像计划设置。
2. Web 前端提供一周左右天数的计划表格，可拖动设置定时录像、预警录像。
3. 支持录像计划一键同步到其他通道。
4. 支持通道配置一键同步到其他通道。
5. 支持按通道配置录像启停、录像类型、主/子码流录像策略等。
6. 支持预警录像与定时录像的独立计划配置。

### 4.4 存储路径、磁盘与存储策略

1. 支持设置录像存储路径。
2. 支持单独设置现有磁盘路径。
3. 支持单独格式化整盘。该操作属于高危运维操作，应要求高权限、二次确认，建议仅在运维模式下开放。
4. 支持存储空间将满预警提示。
5. 存储将满预警支持 Web 页面提示。
6. 支持配置邮箱地址发送邮件预警。
7. 支持配置发件邮箱账号，默认支持 QQ 邮箱预设。
8. 支持循环录制配置，可在存储计划中配置。
9. 支持按盘符单独配置模式：循环录制或录满预警。
10. 支持录像切片策略配置：按时间切片或按文件大小切片。
11. 每个录像切片文件对应 SQLite 数据库索引。
12. 支持存储模块独立封装，应用层仅需调用读取索引文件流位置接口即可返回文件流。

### 4.5 录像索引、回放、预读与缓存

1. 录像文件切片存储，每个切片写入 SQLite 索引。
2. 索引需支持按通道、时间范围、文件路径、切片起止时间、文件大小等查询。
3. 支持实时预览与回放自动无缝加载录像文件。
4. 建立独立预读取模块，可单独封装。
5. 预读取模块负责判断何时读取哪个文件。例如当前流文件读取到末尾时，提前加载下一个文件流的前若干字节或前若干时长。
6. 前一个文件流读取完毕后，与下一个文件流无缝衔接。
7. 用户拖动进度条时，优先只加载对应时间范围索引的视频文件流。
8. 回放、预览、视频下载等场景应利用缓存；缓存命中时直接从缓存读取，无需从硬盘加载。
9. 存储模块对应用层屏蔽底层缓存或硬盘加载细节。
10. 应用层仅发送“读取索引 + 文件流位置”请求，存储模块返回文件流。
11. 缓存大小、预读字节数、预读时长等应可配置。
12. 录像写入采用异步 IO 和内存缓存批量写入，可设置缓存空间，批量顺序写入以提高硬盘写入性能。
13. 内存缓存可采用环形缓存，环形缓存留空一格识别头尾。
14. Linux 下支持开启 `io_uring`。

### 4.6 流媒体分发、RTSP 与实时性

1. 内部支持同一流通道多客户端同时预览。
2. 多客户端分发应具备背压与隔离能力，单客户端卡顿不应拖垮整体。
3. 实时预览优先保证实时性。
4. 带宽或编码处理性能不足时，允许适当丢帧、处理最新帧、降低帧率或码率，以取得平衡。
5. 支持主码流和子码流输出；子码流可关闭。
6. 支持对外 RTSP 流输出，通过一套 URL 传入通道号、账号、密码等参数，直接进行 RTSP 流传输。
7. 对外 RTSP/API 鉴权需与用户权限、API 权限关联。
8. 支持 API 视频预览、照片抓拍、视频下载、预警等能力。

### 4.7 系统信息、时间同步与性能档位

1. 支持显示系统版本号、序列号、系统时间。
2. 支持 NTP 自动同步时间。
3. 支持通过浏览器网页同步本计算机时间。
4. 浏览器显示时间需随秒变化。
5. 录像机启动时自动根据当前运行环境 CPU 核心数量和内存情况设置性能档位。
6. 低配置环境默认关闭子码流。
7. 支持自动识别运行环境是否支持 GPU 加速。
8. 支持自动识别各品牌 GPU 设备。
9. 根据 GPU 识别结果自动调整 FFmpeg 对视频码流的处理命令。
10. 支持显式关闭 GPU 加速，关闭后使用 CPU 处理。
11. 支持性能档位、GPU 开关、子码流开关等配置可查看、可调整。

### 4.8 用户、角色、权限与安全锁定

1. 默认管理员账号为 `admin`。
2. 首次安装并启动 Web 页面时设置 `admin` 密码。
3. 支持添加其他用户。
4. 支持配置角色与权限。
5. 权限包括 API 权限和录像机 Web 功能权限，支持勾选配置。
6. 登录系统需鉴权。
7. Web 登录重复密码错误次数默认 10 次，可配置；达到阈值后锁定 NVR 录像机，默认锁定 10 分钟，可配置。
8. API 请求密码错误/失败默认 100 次后锁定，可单独配置阈值和锁定策略。
9. 权限控制应覆盖预览、回放、下载、抓拍、通道管理、录像计划、存储设置、日志、系统设置、API、RTSP 输出、运维操作等。
10. 高危操作需权限校验和操作审计。

### 4.9 审计日志

1. 支持审计日志查询。
2. 支持日志分类查询，例如登录、通道、录像、存储、API、系统、运维、权限等。
3. 支持日志存储时长设置，默认半年。
4. 到期自动清理日志。
5. 支持日志存储路径设置，默认服务运行目录下。
6. 支持日志检索、筛选、分页查看。
7. 手动删除日志等操作仅通过运维模式开放。
8. 关键操作应记录操作人、时间、来源 IP、操作对象、结果等。

### 4.10 API 与对外接口

1. 支持 API 接口能力。
2. 支持 API 照片抓拍。
3. 支持 API 视频预览。
4. 支持 API 视频下载。
5. 支持 API 预警能力。
6. 支持通过 URL 传入通道号、账号、密码等参数获取 RTSP 流。
7. API 需支持权限校验，与用户角色中的 API 权限关联。
8. API 密码错误失败次数达到阈值后锁定，阈值可单独配置。
9. API 应支持抓拍、预览、下载、预警等接口的审计记录。

### 4.11 智能预警与实验能力

1. 支持画面移动预警。
2. 支持识别到人等预警能力。
3. 预警可触发预警录像。
4. 预警信息可在 Web 页面提示，并可按配置发送邮件。
5. 后续支持人脸识别和车牌识别。
6. 人脸识别、车牌识别作为实验功能，可调用市面成熟库实现。
7. 实验功能应有独立开关，避免影响主录像与预览稳定性。

### 4.12 GPU 与 FFmpeg 自适应

1. 启动时自动识别运行环境是否支持 GPU 加速。
2. 自动识别各品牌 GPU 设备。
3. 根据 GPU 类型和可用性自动调整 FFmpeg 视频码流处理命令。
4. 支持显式关闭 GPU 加速，关闭后使用 CPU 处理。
5. GPU 状态、当前处理模式、性能档位应在系统信息或状态页可查看。
6. GPU 不可用或异常时应可回退 CPU 模式。

### 4.13 运维模式与数据保护

1. 视频文件原则上不能进行删除操作。
2. 仅可通过启动参数启动内部运维模式。
3. 运维模式开启后，可开放视频文件删除、日志删除、修改设备序列号、修改版本号等功能。
4. 非运维模式下，无法执行视频文件删除、日志手动删除、修改序列号、修改版本号等操作。
5. 整盘格式化、循环录制清理等高风险操作需二次确认并记录审计日志。
6. 日志按保留策略自动清理不属于手动删除，应受策略控制。

### 4.14 关于与帮助

1. 关于页面需展示项目开源地址。
2. 关于页面展示版本号、序列号、系统信息等。
3. 帮助页面提供完整使用手册。
4. 帮助页面引导用户完成摄像头接入、通道配置、录像计划、存储设置、回放、权限、API 等配置。
5. 帮助页面支持相关问题搜索和解答。

## 6. 非功能需求

1. 稳定性：摄像头掉线自动重连，单通道异常不影响其他通道。
2. 实时性：预览优先保证实时性，性能不足时按策略丢帧、取最新帧、降帧率或降码率。
3. 并发性：支持多客户端同时预览与回放，流分发应隔离背压。
4. 性能：录像写入采用异步 IO、内存缓存、批量顺序写入；Linux 支持 `io_uring`。
5. 连续性：回放与预览通过预读模块实现文件切片间无缝衔接。
6. 安全性：登录鉴权、角色权限、API 权限、失败锁定、审计日志、高危操作二次确认。
7. 数据保护：视频文件原则上不可删除，删除与修改序列号/版本号仅运维模式开放。
8. 可维护性：存储、预读、流分发、权限、日志等模块解耦封装。
9. 可配置性：录像计划、存储策略、日志策略、邮件、锁定阈值、缓存、预读、GPU、子码流等均可配置。
10. 可扩展性：后续可扩展人脸识别、车牌识别等实验能力。

## 8. 关键验收场景

1. 首次安装启动 Web 页面，可设置 `admin` 密码并登录。
2. 可扫描局域网 ONVIF 摄像头并一键添加，也可手动添加 RTSP、海康、大华等通道。
3. 主页默认加载预览布局，支持 1/4/8/16/32 和自定义网格，支持多布局保存与切换。
4. 通道掉线后显示“设备已掉线”和通道信息，恢复后自动重连；掉线双击打开管理网页，在线双击全屏。
5. 可拖动设置一周录像计划，并支持通道配置和录像计划一键同步。
6. 录像按时间或大小切片，SQLite 生成索引；回放拖动进度条优先加载对应时间范围文件。
7. 回放至文件末尾时预读模块提前加载下一文件，播放无缝衔接。
8. 多客户端同时预览同一通道，单客户端卡顿不影响其他客户端。
9. 存储将满时 Web 提示或邮件预警；按盘符可配置循环录制或录满预警。
10. 视频文件非运维模式不可删除；通过启动参数进入运维模式后可执行删除、日志删除、修改序列号/版本号。
11. 对外 RTSP URL 传入通道号、账号、密码可获取主/子码流；子码流可关闭。
12. API 支持抓拍、预览、下载、预警，并受 API 权限与失败锁定策略控制。
13. 系统自动识别 CPU/内存设置性能档位，低配默认关闭子码流；自动识别 GPU 并调整 FFmpeg 命令，可显式关闭 GPU。
14. 审计日志可按分类查询，默认保留半年，到期自动清理，日志路径可配置。
15. 关于页面展示开源地址，帮助页面提供完整使用手册、配置引导、问题搜索与解答。
